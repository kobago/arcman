# arcman 要件定義書（MVP）

arcman（Archive Manager）は、Webの投稿をブックマークし、消えても読めるようにアーカイブするセルフホストのWebアプリ。MVPは x.com の投稿だけを対象とする。

- 作成日: 2026-10-21
- 出典: チャットでの合意事項と、ヒアリングシート（https://claude.ai/artifact/4Hgf5Zf9LJvMnn3Vzqpevy）の回答
- 括弧内の ID（例: CAP-03）はヒアリングシートの質問 ID

## 1. 前提

| 項目 | 内容 |
|---|---|
| 利用者 | 自分ひとり。外部への公開機能はない |
| 端末 | PCとスマホの両方。レスポンシブ対応 |
| 対象 | x.com の投稿と YouTube の動画。Instagram と一般サイトはMVPの後で検討 |
| 取得元 | fxtwitter API（`GET {base}/2/status/{id}`）。ベースURLは設定で変えられ、自前ホストの FxEmbed に切り替えられる |
| 技術 | バックエンドは Rust と axum、フロントエンドは TypeScript と React の SPA |
| 動かし方 | ビルドした実行ファイルを CLI から起動する。設定とデータは `~/.arcman/` に置く（APP-08） |

## 2. 機能要件

### 2.1 認証

- パスワード方式。DB には Argon2id のソルト付きハッシュだけを保存し、平文は持たない
- 初期パスワードの設定と変更は CLI だけで行う（`arcman set-password`）
- ログインすると HttpOnly Cookie でセッションを発行し、DB で管理する。有効期限は30日
- この端末だけのログアウトと、全端末からのログアウトができる。ログイン中の端末の一覧は作らない（APP-01）
- ログインの失敗が続いたら、一定時間ログインを受け付けない

### 2.2 保存

- Web UI に URL を入力して保存する。改行区切りで複数件をまとめて入力できる（CAP-02）
- 受け付ける URL: `x.com`、`twitter.com`、`mobile.twitter.com`、`fixupx.com`、`fxtwitter.com`、`vxtwitter.com` の投稿URL。クエリは無視する（CAP-01）
- YouTube の動画URLも受け付ける: `youtube.com`（`www.`、`m.`、`music.` を含む）の `/watch?v=`、`/shorts/`、`/live/`、`/embed/`、`/v/`、`youtu.be/`、`youtube-nocookie.com/embed/`
- 保存先は、今開いているフォルダ。「すべて」を開いているときは未分類。タグは後で詳細画面から付ける（CAP-03）
- 同じ投稿をもう一度保存しようとしたら、既存の項目を示して何もしない
- 取得中はすぐにギャラリーに「取得中」のタイルを出し、終わったら差し替える（CAP-04）
- 取得は1件ずつ順番に行う（CAP-10）
- 取得に失敗したら「失敗」のタイルと再試行ボタンを出す。自動のリトライはしない（CAP-05）
- 削除済み、非公開、凍結された投稿は保存せず、理由をエラーとして表示する（CAP-06）
- 引用元の投稿が削除済みや非公開でも本体は保存し、詳細画面に「引用元は表示できません」と出す（CAP-07）

### 2.3 保存する内容

- API のレスポンスは JSON を丸ごと保存し、本文、投稿者、日時を DB のカラムに取り出す
- ローカルに保存するもの:
  - 添付の画像（原寸）
  - 動画（mp4 のうち最もビットレートが高いもの1本）と、そのサムネイル
  - GIF
  - 投稿者のアイコン
  - 引用元の投稿のメディア
  - リンクカードの画像
  - X記事のカバー画像と本文中の画像
- 日本語以外の投稿は、日本語訳も取得して保存する（CAP-08）
- 長文ポストは全文を保存する。X記事も本文と画像をすべて保存する（CAP-09）
- スレッドは保存しない
- YouTube の動画は、oEmbed で取れるタイトル、チャンネル名、チャンネルURLと、サムネイル（あれば最大サイズ）だけを保存する。動画ファイルは保存しない
- いいね数などは保存した時点のスナップショット。再取得の機能は作らない

### 2.4 ギャラリー（一覧）

- ギャラリー風の一覧で、スマホでも同じ
- 画像が複数ある投稿は、画像ごとに独立したタイルにする
- タイルは元の縦横比のまま、高さを揃えて並べる（Googleフォト方式）（GAL-01）
- 列や行の数は画面幅に合わせて自動で決まる（GAL-02）
- 無限スクロールで続きを読み込む（GAL-03）
- タイルに重ねる情報: 動画の再生アイコン、複数枚の投稿であることを示すマーク（例: 1/4）（GAL-04）
- GIF はギャラリー上で音なしのループ再生をする（GAL-05）
- 画像がない投稿は、本文の冒頭数行と投稿者名をタイルに表示する（GAL-06）
- YouTube の動画はサムネイルとタイトルのタイル1枚にする。ショートは縦長にする
- 画像はなくリンクカードの画像だけがある投稿も、本文のタイルにする（GAL-07）
- センシティブな投稿の画像もそのまま表示する（GAL-08）
- 複数のタイルを選んでまとめて操作する機能は作らない（GAL-09）

### 2.5 詳細画面

- タイルをタップすると、画像を拡大表示し、横に投稿の内容を表示する
- スマホは写真アプリ風。画像を全画面で表示し、上にスワイプすると投稿の内容が出る（DET-01）
- スワイプと矢印キーで、タイル単位で前後に移動する（同じ投稿の2枚目にも移動する）（DET-02）
- 画像は画面に収まる大きさで表示し、ズームはしない（DET-03）
- 動画は詳細画面を開いたら音ありで再生する（DET-04）
- YouTube の動画は埋め込みプレーヤー（youtube-nocookie.com）で再生し、タイトル、チャンネル、YouTube で開くリンクを表示する
- 表示する項目: 本文、投稿者（名前、ID、アイコン）、投稿日時、保存日時、いいね・リポスト・表示回数などの数値、引用元の投稿、リンクカード、投票、コミュニティノート、x.com で開くリンク（DET-05）
- 引用元の投稿は詳細画面にだけ表示する
- 画像や動画のファイルを手元に保存するボタンを置く（DET-06）
- 詳細画面ごとに URL を持ち、ブラウザの「戻る」で詳細画面を閉じる（DET-07）
- タグとフォルダは詳細画面で変更できる。フォルダの移動は詳細画面だけで行う（ORG-08）
- 投稿は詳細画面から削除する。確認を出してすぐに削除する（DET-08）。削除は投稿単位で、画像1枚だけを消すことはできない（DET-09）

### 2.6 カテゴリとフォルダ

- Discord のカテゴリとチャンネルのような2段構成: カテゴリ → フォルダ。入れ子はない
- フォルダはカテゴリに属さなくてもよい
- 1件の投稿は1つのフォルダにだけ入る。どのフォルダにも入らない未分類も許可する（ORG-01）
- 左のサイドバーに「すべて」「未分類」、カテゴリ（折りたたみ可）、フォルダを並べる。件数は表示しない（ORG-02）
- フォルダを選ぶと、そのフォルダの投稿だけがギャラリーに出る
- カテゴリとフォルダは、作成、名前の変更、削除、ドラッグでの並べ替えができる。フォルダは別のカテゴリへも移せる（ORG-07）
- 同じ名前のフォルダも作れる（ORG-05）
- フォルダを削除すると、中の投稿も削除する。削除される投稿の件数を表示して確認する（ORG-04）
- カテゴリを削除すると、中のフォルダはカテゴリなしのフォルダとして残る（ORG-03）
- スマホではサイドバーを左から引き出すドロワーにする（ORG-06）

### 2.7 タグ

- タグは付けるときにその場で作れる。文字を入力すると既存のタグを候補に出し、なければ新規作成する（TAG-01）
- 表記ゆれを吸収する: 大文字と小文字を区別しない、前後の空白を取り除く、先頭の `#` を取り除く、全角と半角を統一する（TAG-02）
- 階層はなく、すべて同じ階層（TAG-05）
- 投稿本文のハッシュタグは、自動ではタグにしない（TAG-04）
- タグの管理画面の機能（TAG-03）:
  - 一覧（各タグの件数つき）
  - 名前の変更
  - 削除
  - タグを選んで、そのタグの付いた投稿をギャラリーで表示する
  - タグごとの色
  - 名前順と件数順の並べ替え

### 2.8 検索と絞り込み

- キーワードは本文とタグ名を部分一致で検索する（SRC-01）
- 検索の範囲は今開いているフォルダの中。「すべて」を開いていれば全体（SRC-02）
- キーワードとは別にタグを選んで絞り込める。複数選ぶと AND（SRC-03）
- 保存日時を期間で絞り込む。開始日と終了日を入力する（SRC-04）
- 並び順は保存日時の昇順と降順を切り替えられる
- メディアの種類（画像、動画、YouTube、テキストのみ）と投稿者でも絞り込める（SRC-06）。画像、動画、テキストのみは x.com の投稿だけが対象
- 絞り込みの条件は URL に反映し、再読み込みやブックマークでも残る（SRC-05）

### 2.9 設定と表示

- Web の設定画面を作る。環境変数で設定した値は、設定画面の初期値になる。画面で一度保存した値は環境変数より優先する（APP-05）
- 表示言語は日本語と英語。翻訳は表示言語に関係なく日本語（APP-02）
- テーマは OS の設定に合わせつつ、画面でも切り替えられる（APP-03）
- PWA には対応しない（APP-04）
- データのエクスポート機能は作らない。`~/.arcman/` をコピーすればバックアップになるようにする（APP-06）
- ストレージの使用量は表示しない（APP-07）

## 3. MVP の対象外

- x.com と YouTube 以外のサイト
- YouTube の動画ファイルのダウンロード
- URL 入力以外の保存の入口（共有メニュー、ブラウザ拡張、一括インポート、自動取り込み）
- スレッドの保存、数値の再取得
- メモ機能、タグの階層、タグの統合、複数選択での一括操作
- 画像のズーム、画像1枚単位の削除
- PWA、エクスポート、ストレージ使用量の表示、ログイン中の端末の一覧
